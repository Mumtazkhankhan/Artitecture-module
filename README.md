# Artitechure module
No            Module Name                                                Main Features
1         Cache Memory Module                                        Cache hits, misses, FIFO and LRU replacement algorithms
2         Instruction Set Architecture (ISA) Module                  Simulate instructions such as MOV, ADD, SUB, LOAD and STORE
3         CPU Design and Control Unit Module                         Simulate registers, ALU operations, and the fetch-decode-execute cycle
4          Memory and Addressing Module                               Simulate memory addresses, address calculations, and addressing modes
5        I/O and Bus Architecture Module                            Simulate data transfer between CPU, memory, and input/output devices
